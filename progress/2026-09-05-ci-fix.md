# CI Failure Fix

## Root Cause

GitHub Actions run `#107` for commit `a49df1e` completed installation and Ruff lint,
then failed in the **Ruff format** step with exit code 1. Ruff 0.16.5 identified three
unformatted files:

- `src/nanodesign/v0/learnability.py`
- `src/nanodesign/v0/results.py`
- `tests/test_evaluation.py`

The formatter only collapsed line wrapping; no expression, branch, test assertion,
data, model, loss, training result, or scientific behavior changed.

An initial local `pytest` invocation also failed collection because the existing HPC
Python 3.12 environment did not have this checkout installed as an editable package.
That was a local environment mismatch, not the GitHub failure: the GitHub Install
step had succeeded and the run reached Ruff. The repository was installed locally
with `pip install -e . --no-deps` after confirming its dependencies were already
present. A literal reinstall of all extras on this HPC login environment additionally
encountered missing system `Python.h` while building DockQ 2.1.3; Ubuntu GitHub
Actions does not have that failure.

## CI Configuration Audited

`.github/workflows/ci.yml` triggers one `test` job on every `push` and
`pull_request`. It uses `ubuntu-latest`, Python 3.12, and executes:

```bash
python -m pip install -e ".[data,evaluation,model,dev]"
python -m ruff check --output-format=github src tests
python -m ruff format --check src tests
python -m pytest
nanodesign-v0 model-summary --config configs/v0.yaml
```

The `dev` extra in `pyproject.toml` pins `ruff==0.16.5`; the local reproduction also
reported `ruff 0.16.5`. Python is consistently constrained to `>=3.12,<3.13`, and the
workflow explicitly selects Python 3.12.

## Files Changed

- `src/nanodesign/v0/learnability.py`: Ruff-only line wrapping.
- `src/nanodesign/v0/results.py`: Ruff-only function-signature wrapping.
- `tests/test_evaluation.py`: Ruff-only comprehension wrapping.
- `scripts/check.sh`: one local entry point mirroring every CI validation command.
- `AGENTS.md`: commit/push guardrails for coding agents.
- `progress/2026-09-05-ci-fix.md`: this audit record.
- `progress/README.md`: progress-log index entry.

## Fix

Ran Ruff 0.16.5 formatting over `src` and `tests`, inspected the resulting diff, and
confirmed all three changes were whitespace/line-layout only. No CI check, test, or
assertion was deleted, skipped, weakened, or disabled.

Added `scripts/check.sh` with `set -euo pipefail`. It runs the same Ruff lint, Ruff
format, pytest, and CLI smoke commands as GitHub Actions, so any failure stops the
script with a non-zero exit code.

## Validation

Local environment: Python 3.12.13, Ruff 0.16.5.

```text
python -m ruff check --output-format=github src tests
→ PASS (exit code 0)

python -m ruff format --check src tests
→ PASS (45 files already formatted, exit code 0)

python -m pytest
→ PASS (100 passed, 1 skipped, exit code 0)

nanodesign-v0 model-summary --config configs/v0.yaml
→ PASS (6,849,538 parameters, within v0 budget, exit code 0)
```

The consolidated `./scripts/check.sh` was then run from the repository root to
revalidate the same complete command sequence before commit.

## Prevention

`AGENTS.md` now requires every Python-changing commit to run:

```bash
python -m ruff format src tests
./scripts/check.sh
```

Agents must not commit or push while Ruff, pytest, or the CLI smoke test fails, and
must not weaken checks to obtain a green result. Ruff remains pinned at 0.16.5 through
the installed `dev` extra, keeping local and GitHub formatting behavior aligned.
